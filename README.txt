Pent.T Shop — Laravel POS

ระบบ Laravel POS อยู่ในโฟลเดอร์ laravel-pos และเก็บข้อมูลใน MySQL/MariaDB ของ XAMPP ที่ฐานข้อมูล cafe_pos

เริ่มใช้งาน: เปิด XAMPP Control Panel แล้ว Start MySQL จากนั้นเปิด Terminal ในโฟลเดอร์ laravel-pos และรัน:
  npm run serve
เปิดเว็บที่ http://127.0.0.1:8000/login

ข้อมูลเดิมจาก SQLite และออเดอร์จากฐาน cafe_db ถูกย้ายเข้า cafe_pos แล้ว
บัญชีเริ่มต้น: admin@pentt.local / password
คู่มือเพิ่มเติมอยู่ใน laravel-pos/README.md
ไฟล์ PHP รุ่นเดิมยังเก็บไว้ในโฟลเดอร์หลัก
